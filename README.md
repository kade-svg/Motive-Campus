# Motive Campus

A standalone school organiser made in the Motive design style.

## Included
- Overview dashboard
- Custom Monday–Friday timetable
- Class library with teacher, room, description, tasks/resources and colour
- Notes with tags, class links, search and filtering
- Dark/light mode
- Local student profile
- Responsive phone + desktop layout
- PWA manifest and service worker for GitHub Pages / installable web-app use
- Local-first storage using browser `localStorage`
- No backend, server, account, API key or external dependency required

## Run
Open `index.html` in a browser.

For full PWA/service-worker behaviour, serve the folder from a web server such as GitHub Pages, VS Code Live Server, or any static hosting service.

## GitHub Pages
Upload the contents of this folder to a repository, enable GitHub Pages, and use the generated Pages URL.

## Privacy
The timetable, class details, notes and profile are stored in the browser on the device. Clearing the site's browser storage will remove local data.

Made for the Motive app ecosystem.
